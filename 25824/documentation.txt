Story 25824 — Neuer Tab "Genehmigungen"

Source: `25824/update_sets.txt`, captured by IZEAE65. Story: `25824/story.txt`.

On Quote (`sn_quote_mgmt_core_quote`) the related list **Genehmigungen** shows the `sysapproval_approver` rows for that Quote. The link is `source_table` + `document_id`, not `sysapproval`. Open, approved, and rejected rows all stay in the list. The newest change is first.

No new table. No new Approve or Reject button. No ACL. No change to the `state` choices.

The file contains six payloads. The list layout is pasted twice; it is one record.

## Relationship

`sys_relationship` **Genehmigungen**, sys_id `4d1f659568c81f10b0e4e691f7bdbeba`.

- Applies to: `sn_quote_mgmt_core_quote`
- Queries from: `sysapproval_approver`
- Application: Quote Management Data Model (`sn_quote_mgmt_core`)
- Created 2026-10-19 14:46, updated 2026-10-20 12:22

```javascript
(function refineQuery(current, parent) {
    current.addQuery('source_table', 'sn_quote_mgmt_core_quote');
    current.addQuery('document_id', parent.sys_id);
    current.orderByDesc('sys_updated_on');
})(current, parent);
```

There is no filter on `state`, so a rejected approval remains on the tab. `sys_updated_on` descending is the Zeitpunkt: approve and reject update that field, and the latest row is at the top.

The relationship name is the tab title.

Default view, LBBW Quote, and CSM FSM Configurable Workspace have the tab and no column layout in this update set. On those views the list uses the columns already defined for `sysapproval_approver`.

## What this update set does not contain

- No read or write ACL on `sysapproval_approver`. A user sees a row when the existing approval ACLs allow it.
- No UI action. Approve and Reject (Genehmigen / Ablehnen) are the existing buttons on the approval record. They show when `state` is `requested` and the logged-in user is `approver`.
- No record that creates an approval. The tab only lists rows that already exist, linked by `source_table` = `sn_quote_mgmt_core_quote` and `document_id` = the Quote sys_id.

## Story criteria against this update set

- The tab **Genehmigungen** is on Default view, LBBW Quote, CSM FSM Configurable Workspace, and SOM Workspace, with no role on the related list.
- On SOM Workspace the list shows `state` and `sys_updated_on`, and it includes every state because the relationship does not filter `state`.
- The row opens `sysapproval_approver`. Approval and rejection are the existing buttons on that record.
